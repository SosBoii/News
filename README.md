# 🗞️ מה קורה – פיד חדשות אישי

פיד קצר ונקי, בלי פוליטיקה. כולל עולם, ישראל, טראמפ, כלכלה, טכנולוגיה, מדע ועוד.
- נסרק אוטומטית פעמיים ביום.
- Gemini מסנן את הפוליטיקה ומסכם כל כתבה בעברית.
- נפתח מאייקון במסך הבית של הטלפון.
- חינם לגמרי, בלי שרת ובלי מסד נתונים.

```
GitHub Actions (פעמיים ביום)
   └─ fetch.py: RSS ← סינון מילים ← Gemini ← איחוד כפילויות ← תמונות
        └─ feed.json  ──►  GitHub Pages  ──►  index.html בטלפון
```

"קראתי", "שמור" וההגדרות נשמרים **רק בטלפון** (בזיכרון הדפדפן).

---

## 🚀 הקמה (פעם אחת, כ-15 דקות)

### 1. מאגר ב-GitHub
1. נכנסים ל-github.com ומתחברים, או פותחים חשבון בחינם.
2. למעלה מימין לוחצים **+** ואז **New repository**.
3. ממלאים:
   - **Repository name:** למשל `ma-kore`. השם יופיע בכתובת.
   - **Public**. זה נדרש ל-Pages בחינם. אין במאגר שום דבר סודי, המפתח נשמר בנפרד.
   - **לא** מסמנים "Add a README".
4. לוחצים **Create repository**.

### 2. העלאת הקבצים
> ⚠️ **אל תגררו את כל התיקייה `news-feed`.** בהעלאה דרך האתר GitHub לא מכבד את `.gitignore`, ואז גם קובץ המפתח היה עולה.

1. במחשב, מתוך התיקייה `news-feed`, מריצים:
   ```
   .venv\Scripts\python prepare_upload.py
   ```
   הפקודה יוצרת תיקייה `_upload` עם הקבצים הנכונים בלבד, ובודקת שהמפתח לא נמצא באף אחד מהם.
2. במאגר החדש לוחצים **uploading an existing file**.
3. פותחים את `_upload` בסייר הקבצים, מסמנים את **כל מה שבתוכה** (Ctrl+A) וגוררים לחלון של GitHub.
   - קבצים שמתחילים בנקודה (`.github`, `.gitignore`, `.nojekyll`) מוסתרים כברירת מחדל. ב-Windows: סייר הקבצים, **תצוגה** ואז **הצג** ואז **פריטים מוסתרים**.
   - **חשוב שהתיקייה `.github` תעלה.** בלעדיה אין סריקה אוטומטית.
4. לוחצים **Commit changes**.

### 3. המפתח של Gemini (Secret)
1. במאגר: **Settings**, אחר כך **Secrets and variables**, ואז **Actions**.
2. לוחצים **New repository secret**.
3. ממלאים:
   - **Name:** `GEMINI_API_KEY` (בדיוק ככה).
   - **Secret:** מדביקים את המפתח. אפשר להעתיק מ-`gemini_key.txt` במחשב.
4. לוחצים **Add secret**. אחרי השמירה GitHub לא מציג את המפתח לאף אחד, גם לא לך.

### 4. הרשאה לסריקה לשמור את הפיד
1. **Settings**, אחר כך **Actions**, ואז **General**.
2. גוללים ל-**Workflow permissions**, בוחרים **Read and write permissions** ולוחצים **Save**.

### 5. הפעלת האתר (GitHub Pages)
1. **Settings** ואז **Pages**.
2. **Source:** בוחרים **Deploy from a branch**.
3. **Branch:** בוחרים `main` ואת התיקייה `/ (root)`, ולוחצים **Save**.
4. אחרי כדקה תופיע כתובת כמו `https://<שם-משתמש>.github.io/ma-kore/`.

### 6. סריקה ראשונה (ידנית)
1. **Actions**, ואז בצד **סריקת חדשות**, ואז **Run workflow** ושוב **Run workflow**.
2. אחרי 2–4 דקות אמור להופיע ✓ ירוק.
3. אם מופיע ❌, לוחצים עליו ורואים איזה שלב נכשל. בטבלה למטה יש פתרונות.

### 7. בטלפון
1. פותחים את הכתובת מסעיף 5.
2. מוסיפים את הדף למסך הבית:
   - **אייפון (Safari):** כפתור השיתוף ⬆️, ואז **הוסף למסך הבית**.
   - **אנדרואיד (Chrome):** תפריט ⋮, ואז **הוספה למסך הבית**.

## ✏️ שינויים בלי קוד

את כל ההגדרות עורכים ב-`config.yaml`, ישירות באתר של GitHub (גם מהטלפון): לוחצים על הקובץ, אחר כך ✏️, ואז **Commit changes**.
השינוי ייכנס בסריקה הבאה. אפשר גם להריץ סריקה ידנית (סעיף 6).

| רוצה ל... | איפה ב-`config.yaml` |
|---|---|
| לחסום מילה | `keywords` ← `block` ← מוסיפים שורה `- המילה` |
| להוריד נושא לסוף הטאב | `keywords` ← `quiet` |
| לשנות כמה כתבות יש בטאב | `max:` של הטאב |
| להוסיף אתר | `sources:` של הטאב. מוסיפים `name` ו-`url` (כתובת RSS) |
| לשנות מה ה-AI מסנן | `ai` ← `instructions` (בעברית חופשית) |

> אפשר גם לחסום מילה ישר מהטלפון: ⚙️ ← "מילים לחסימה". זה משפיע רק על הטלפון הזה.

**שעות הסריקה:** נקבעות ב-`.github/workflows/scan.yml`, בשורות `cron`. השעות שם הן ב-UTC (שעון ישראל פחות 3 שעות בקיץ, או פחות 2 בחורף).

## 👫 משתמש נוסף (למשל בת זוג)

**אותו פיד:** פשוט שולחים לה את הכתובת. "קראתי" ו"שמור" יהיו נפרדים לכל טלפון.

**פיד עם נושאים אחרים:**
- מעתיקים את `config.yaml` לקובץ חדש, למשל `config-partner.yaml`, ועורכים.
- ב-`scan.yml` מוסיפים שורה אחרי `python fetch.py`:
  ```
  python fetch.py --config config-partner.yaml --out feed-partner.json
  ```
- מוסיפים גם את `feed-partner.json` לשורה `git add`.
- **הדף עצמו עוד לא תומך בפיד שני.** צריך שינוי קטן ב-`index.html` כדי שיקרא את `feed-partner.json`. נעשה אותו כשתרצו להוסיף אותה.

## 🛠 פתרון בעיות

| מה רואים | מה לעשות |
|---|---|
| ❌ בשלב "בדיקות" | משהו בקוד או ב-`config.yaml` נשבר. הפיד הקודם לא נדרס. לבדוק את השינוי האחרון ב-`config.yaml` (בדרך כלל הזחה, או מירכאות חסרות) |
| ❌ בשלב "שמירת feed.json" עם `403` | לא הוגדר סעיף 4 (Read and write permissions) |
| בדף, ⚙️ ← "AI לא פעל… (no GEMINI_API_KEY)" | ה-Secret חסר או השם שלו לא מדויק (`GEMINI_API_KEY`) |
| "AI לא פעל… (no model available…)" | Gemini היה עמוס, או שנגמרה המכסה היומית. הפיד ממשיך עם סינון מילים, ובסריקה הבאה זה בדרך כלל חוזר |
| הדף מציג פיד ישן | ⚙️ מראה מתי הייתה הסריקה האחרונה. ב-**Actions** בודקים שהסריקות רצות |
| הסריקות הפסיקו אחרי חודשיים | GitHub משבית סריקות מתוזמנות במאגר שלא היה בו שינוי 60 יום. נכנסים ל-**Actions** ולוחצים **Enable workflow**. הסריקה עצמה שומרת שינוי ב-`feed.json` כל יום, אז בדרך כלל זה לא יקרה |
| אתר מסוים לא מחזיר כתבות | ⚙️ ← "מקורות" מראה מה נכשל. אפשר להחליף לו `url` ב-`config.yaml` |

## 💻 הרצה מקומית (למפתחים)

```
cd news-feed
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pytest
.venv\Scripts\python -m pytest -q tests     # בדיקות
.venv\Scripts\python fetch.py               # סריקה ← feed.json
preview.bat                                 # תצוגה בדפדפן: http://localhost:8765
```

המפתח בהרצה מקומית: שורה אחת בקובץ `gemini_key.txt`. הקובץ מוחרג מ-git ולעולם לא עולה.

| קובץ | מה הוא |
|---|---|
| `index.html` | הדף. קובץ אחד, בלי ספריות |
| `fetch.py` | הסריקה: RSS, סינון, איחוד כפילויות ותמונות |
| `ai.py` | Gemini: סינון, סיכום בעברית, 🔴 ו"5 הדברים" |
| `config.yaml` | כל ההגדרות |
| `feed.json` | התוצאה. נוצר אוטומטית, לא עורכים ידנית |
| `.github/workflows/scan.yml` | התזמון של הסריקה |
| `prepare_upload.py` | מכין את התיקייה `_upload` להעלאה בטוחה. רק מקומי |
